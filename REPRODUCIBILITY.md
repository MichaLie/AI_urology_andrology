# Reproducibility Notes

## Repository Scope

This repository reproduces the figures, tables, and audit summaries from locked screening outputs used in the manuscript:

> Clinical readiness of artificial intelligence in urology and andrology: a PubMed-indexed scoping review and evidence map

The repository is intended as a public reproducibility package, not as a live systematic-review platform.

## Deterministic Outputs

The following outputs are regenerated from the locked CSV/JSON files in `data/`:

- PRISMA-ScR flow diagram.
- Publication-trends figure.
- Review-burden figure.
- Readiness-map figure.
- Translation/collaboration figure assembled from bundled assets.
- Anchor evidence matrix.

The release also bundles locked analysis tables used by the article, including `readiness_anchor_summary_by_use_case.csv`, `tiered_readiness_summary.csv`, and `reporting_frameworks.csv`. These are public data artifacts, not live-generated files.

## Outputs That Require External Access

The PubMed harvester can rerun the original search strategy, but live PubMed results may change over time. Rerunning retrieval therefore recreates a new search snapshot rather than the locked review corpus.

The AI-assisted title/abstract screening script requires:

- PubMed abstracts or an equivalent local screening table.
- API access to the selected large-language-model backend.
- The same prompt/schema reported in the manuscript supplement.

The public screening table intentionally excludes abstract text. The repository therefore reproduces manuscript outputs from locked decisions; it does not fully rerun title/abstract screening without reconstructing abstracts and API access.

## Human Adjudication

Human screening, adjudication, and audit decisions are represented in the released decision tables. These decisions are not regenerated by code.

## Suggested Command

After installing dependencies:

```bash
python scripts/rebuild_all.py
```

Expected output directory: `figures/`.

## Versioning

For public release, create a release tag such as `v1.0.0` and archive that release through Zenodo or OSF. Cite the resulting DOI in the manuscript Data Availability and Code Availability statements.
